# Learning Manual

## Learning Goal

After reading this guide, the learner should understand what the project does,
how it runs, where the important code lives, and how to ask an AI coding agent
for changes safely.

## Reading Path

1. Start with the README.
2. Open the main entry point.
3. Follow the user request or command flow.
4. Read the core modules.
5. Read tests to understand expected behavior.

## Suggested Exercises

- Change a small UI label or CLI message.
- Add a small test.
- Trace one request from entry point to output.
- Ask an AI agent to explain one module, then verify the answer against source.

## Questions To Check Understanding

1. What command starts the project?
2. Which file is the main entry point?
3. Where does configuration come from?
4. Which tests cover the core behavior?
