Project Overview
maintainers
Verified

tracedocs is a deterministic, offline CLI that scans a repository and writes a structured study-docs/ package.

  • Python 3.9+ with zero runtime dependencies.
  • Extracts commands, entry points, env-var names, routes, entities, tests, and deployment signals.
  • Writes manuals plus an evidence trail for agent handoff.
